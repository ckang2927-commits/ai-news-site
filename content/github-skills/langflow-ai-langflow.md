# Langflow：可视化的 LLM 应用构建平台

## 项目简介

Langflow 是一个低代码的 LLM 应用构建平台，通过拖拽式可视化界面让 AI 应用开发变得像搭积木一样简单。它将 LangChain 的组件能力与可视化工作流编辑器相结合，使得非技术用户也能构建复杂的 AI 应用。

## 功能介绍

### 核心功能

- **可视化工作流编辑**：拖拽组件构建 AI 应用流程，实时查看数据流向
- **丰富组件库**：内置 LLM、Prompt、Agent、Tool、Memory 等 100+ 个组件
- **一键导出部署**：编辑完成后可导出为 Python 代码或直接通过 API 部署

### 应用场景

- 快速原型开发：产品经理和非技术团队成员快速搭建 AI 应用原型
- AI 教学演示：在教学环境中直观展示 LLM 应用的组件构成和数据流转
- 企业内部工具：业务人员自主搭建简单的 AI 辅助工具

### 优势特点

1. 零代码门槛：无需编程经验即可构建复杂的 LLM 应用
2. 完全兼容 LangChain：底层基于 LangChain 组件，可以无缝扩展
3. 实时调试：每个节点都可以单独测试和调试，快速定位问题
