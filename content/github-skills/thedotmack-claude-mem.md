# Claude Mem：为 Claude 注入长期记忆能力

## 项目简介

Claude Mem 是一个为 Claude AI 提供长期记忆功能的浏览器扩展，解决了 AI 对话无法跨会话保持记忆的核心痛点。安装后，Claude 能够在不同聊天会话之间记住用户的偏好、习惯和关键信息，让对话体验更加连续和个性化。

## 功能介绍

### 核心功能

- **长期记忆存储**：跨会话保存关键信息，自动注入到后续对话上下文
- **记忆管理界面**：用户可通过弹出面板查看、编辑和删除已存储记忆
- **智能记忆提取**：AI 自动识别对话中的重要信息并保存为记忆条目

### 应用场景

- 日常 AI 助手：让 Claude 记住用户的个人信息和工作习惯
- 持续项目协作：在长期项目中保持上下文连续性
- 学习辅助：记录学习进度和重点关注内容，持续提供个性化指导

### 优势特点

1. 隐私优先：所有记忆数据存储在本地浏览器中，不会上传云端
2. 无缝集成：安装后自动工作，无需复杂配置
3. 智能管理：自动提取重要信息，减少用户手动管理记忆的负担
