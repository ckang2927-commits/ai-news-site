# Gmail 邮件管理

## 功能概述

Gmail 邮件管理 Skill 提供完整的 Gmail 操作能力，包括收件箱管理、邮件搜索、摘要生成和回复草拟。

## 核心功能

- **收件箱管理**：阅读、分类、归档邮件
- **邮件搜索**：快速搜索历史邮件
- **摘要生成**：自动生成邮件摘要
- **回复草拟**：根据上下文生成回复草稿

- 日常邮件处理
