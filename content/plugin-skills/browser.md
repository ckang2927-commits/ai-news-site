# 浏览器控制

## 功能概述

浏览器控制 Skill 允许通过编程方式控制 Codex 内置浏览器，实现页面导航、元素交互、截图和页面状态读取等功能。

## 核心功能

- **页面导航**：打开 URL、前进后退、刷新
- **元素交互**：点击、输入、选择下拉框
- **页面读取**：提取文本、截图、获取 DOM 状态
- **本地测试**：支持 localhost 和 file:// 协议

## 使用场景

- 前端页面自动化测试
