# 电脑操作

## 功能概述

电脑操作 Skill 通过 SendInput 和 UI Automation 技术，实现 Windows 桌面应用的自动化操控。

## 核心功能

- **应用控制**：启动、关闭和管理 Windows 应用
- **UI 交互**：模拟鼠标点击、键盘输入
- **界面读取**：识别窗口元素和文本内容
- **文件操作**：文件系统的读写和管理

## 使用场景

- 桌面应用的自动化工作流
- 跨应用的数据迁移和整合
- 重复性操作的自动化
