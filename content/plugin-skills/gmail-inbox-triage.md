# Gmail 收件箱分类

## 功能概述

Gmail 收件箱分类 Skill 自动将邮件按紧急程度分类，帮助用户优先处理最重要的邮件。

## 核心功能

- **智能分类**：将邮件分为紧急、待回复、等待中、仅供参考
- **优先级排序**：按重要程度排序邮件
- **批量操作**：对同类邮件进行批量处理
- **提醒设置**：设置跟进提醒

## 使用场景

- 每日收件箱清理
- 重要邮件的优先处理
- 邮件工作流管理
- 减少邮件积压
