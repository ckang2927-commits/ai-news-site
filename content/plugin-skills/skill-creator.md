# Skill 创建器

## 功能概述

Skill 创建器 Skill 指导用户创建和更新 Codex 的 Skill 文件，用于扩展 Codex 的专业知识和能力。

## 核心功能

- **Skill 生成**：从需求自动生成 Skill 文件
- **模板管理**：使用标准模板创建 Skill
- **能力扩展**：添加新的专业领域知识
- **测试验证**：验证 Skill 的正确性

## 使用场景

- 为特定领域创建专业 Skill
- 扩展现有 Skill 的功能
- 创建团队共享的 Skill
