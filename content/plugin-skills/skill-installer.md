# Skill 安装器

## 功能概述

Skill 安装器 Skill 帮助用户从官方精选列表或 GitHub 仓库安装新的 Codex Skills。

## 核心功能

- **精选列表**：浏览官方推荐的 Skill 列表
- **GitHub 安装**：从 GitHub 仓库安装 Skill
- **版本管理**：管理已安装 Skill 的版本
- **依赖处理**：自动处理 Skill 间的依赖关系

## 使用场景

- 扩展 Codex 的功能
- 安装社区贡献的 Skill
- 私人仓库的 Skill 安装
