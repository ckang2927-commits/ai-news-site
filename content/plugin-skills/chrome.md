## 功能概述

Chrome 浏览器控制 Skill 可以操控用户本机的 Chrome 浏览器，利用现有的登录状态、Cookie 和扩展进行操作。

- **会话复用**：使用已有的 Chrome 登录状态

- **页面操作**：完整的浏览器交互能力
- **扩展支持**：使用已安装的 Chrome 扩展
