# Yeet 发布工具

## 功能概述

Yeet 是一个快速发布工具，能够将本地代码变更自动提交、推送并创建 Pull Request，简化发布流程。

## 核心功能

- **一键发布**：确认变更范围后自动提交和推送
- **自动 PR**：自动创建 Draft PR
- **变更确认**：展示变更范围供确认
- **分支管理**：自动管理发布分支

## 使用场景

- 快速原型发布
- 小规模代码变更的提交
- 日常开发中的快速分享
