# GitHub 评论处理

## 功能概述

GitHub 评论处理 Skill 专注于处理 Pull Request 中的审查反馈，能够检查和回复未解决的审查评论。

## 核心功能

- **评论分析**：识别和分类未解决的审查意见
- **回复生成**：自动生成专业的回复内容
- **状态更新**：标记已解决和待处理的评论
- **变更跟进**：追踪代码修改后的评论状态

## 使用场景

- PR 审查后的反馈处理
- 代码迭代中的评论管理
- 团队协作的审查流程优化
