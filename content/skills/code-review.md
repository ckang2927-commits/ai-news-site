# 代码审查

## 功能概述

代码审查 Skill 模拟资深代码审查者，对提交的代码进行全面审查，涵盖逻辑正确性、性能优化和安全性三个方面。

## 核心功能

- **逻辑审查**：检查边界条件、空值处理、并发问题
- **性能审查**：识别不必要的循环、内存泄漏、查询优化点
- **安全审查**：检测 SQL 注入、XSS、CSRF 等常见漏洞
- **最佳实践**：推荐代码风格和架构改进

## 使用场景

- Pull Request 的自动审查
- 代码提交前的质量检查
- 遗留代码的审计和重构建议
