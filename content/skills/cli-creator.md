# CLI 工具创建器

## 功能概述

CLI 工具创建器可以根据 API 文档、OpenAPI 规范、现有 curl 示例或 SDK，快速生成可组合的命令行工具。

## 核心功能

- **自动生成 CLI**：从 API 文档自动解析生成命令行接口
- **可组合命令**：支持管道和链式调用
- **认证管理**：内置 API 密钥和 OAuth 支持
- **JSON 输出**：默认输出结构化 JSON，便于后续处理

## 使用场景

- 为内部 API 快速创建 CLI 工具
- 将常用的 API 调用封装为命令行
- 构建 DevOps 工具链
