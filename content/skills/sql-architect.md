# SQL 架构师

## 功能概述

SQL 架构师是一个数据库专家 Skill，能够将自然语言描述转化为高效的 SQL 查询，并提供索引优化和查询性能调优建议。

## 核心功能

- **自然语言转 SQL**：用中文描述需求，自动生成 SQL
- **查询优化**：分析执行计划，提供索引和优化建议
- **多数据库支持**：兼容 MySQL、PostgreSQL、SQLite 等
- **数据建模**：辅助数据库表结构设计

## 使用场景

- 快速编写复杂查询
- 优化慢查询和性能调优
- 数据库表结构设计
- SQL 学习和教学
