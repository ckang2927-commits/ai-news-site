# 测试用例生成器

## 功能概述

测试用例生成器能够自动为数据处理函数生成全面的单元测试用例，覆盖正常路径、边界条件和异常情况。

## 核心功能

- **自动生成**：分析函数签名和逻辑，自动生成测试代码
- **边界覆盖**：自动识别边界条件和极端输入
- **异常测试**：生成错误处理和异常路径的测试
- **多框架支持**：支持 pytest、unittest 等测试框架

## 使用场景

- 数据管道函数的测试覆盖
- API 接口的单元测试
- 算法函数的正确性验证
- 重构代码的回归测试
