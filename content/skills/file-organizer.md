# 文件整理器

## 功能概述

文件整理器是一个智能文件管理工具，能够分析文件内容上下文、查找重复文件、建议更好的组织结构，并自动执行整理操作。

## 核心功能

- **智能分类**：根据文件内容和类型自动分类
- **重复检测**：查找并移除重复文件
- **结构优化**：建议更好的文件夹结构
- **清理建议**：识别不常用文件和临时文件

## 使用场景

- 桌面和工作目录的定期整理
- 项目文件的结构优化
- 重复文件的清理
- 下载文件夹的自动分类
