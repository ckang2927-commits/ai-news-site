GH Fix CI

功能概述

GitHub CI 修复 Skill 帮助诊断和修复 GitHub Actions 中运行失败的 CI 检查，快速定位问题根因。

核心功能

  • 失败分析：分析 CI 日志，定位错误原因
  • 修复建议：提供具体的修复方案和代码修改
  • 配置优化：优化 CI 配置文件
  • 重试管理：管理 CI 运行的重试和恢复

使用场景

  • CI 构建失败的快速修复
  • GitHub Actions 配置调试
  • 测试环境问题的排查
